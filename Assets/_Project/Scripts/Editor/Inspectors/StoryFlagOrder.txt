# The story flags in the order they happen, for the [StoryFlag] dropdown (StoryFlagDrawer).
# It only changes how the dropdown shows them: the flags keep their names, so saves keep working.
#   ## Title    a chapter
#   flag        the main line, numbered in this order
#   - flag      a side quest or a place off the main line: any time during its chapter
#   * flag      a state that is set and cleared again, not a step of the story
# Flags used in the project but not listed here show at the end, under "Not in the order yet".
# Text after # is a note for whoever edits this file; the dropdown does not show it.
